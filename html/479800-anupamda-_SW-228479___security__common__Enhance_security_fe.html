[SW-228479]: security: common: Enhance security features in Makefile with additional compiler flags

This patch enhances the build configuration by
introducing additional compiler and linker flags aimed
at improving binary security:

- Enables PIE (`-fPIE`, `-pie`) for position-independent
  executables.
- Enables RELRO (`-Wl,-z,relro`) and immediate binding
  (`-Wl,-z,now`) to harden the binary against certain
  memory corruption attacks.
- Adds `_FORTIFY_SOURCE=2` for lightweight buffer
  overflow protection.
- Enables `-O3` for maximum optimization.
