Commit Message

[SW-232549] g3: clear ipm msg on timeout

If a software interrupt is missed, the message remains in the mailbox
and is never cleared by the management firmware, leading to a complete
IPM stall. This fix ensures that, in the event
of a timeout, msg id is explicitly cleared maintain normal operation.
