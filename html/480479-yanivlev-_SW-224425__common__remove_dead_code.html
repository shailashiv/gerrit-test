Commit Message

[SW-224425] common: remove dead code

The value of power_timestamp and thermal_throttle is overwritten on a
throttling event. The value saved in pid.c is never being used. There
isn't any power\thermal event during init stage, so no need to take a
timestamp of a non-existing event. Following recent changes nearby, this
line is misleading and should be removed.
Signed-off-by: Yaniv Levinsky <ylevinsky@habana.ai>
