Commit Message

[FSW-1317] fs1: dup: add api to config master dup grp

In FS1, we need to configure 160 instances of CU_RRTR rate limiters on
the compute die. Since FS1 dup groups support broadcasting to only 32
addresses, multiple dup groups are required. To speeden up the
configuration, a master dup group is used to broadcast writes from ARC
to the multiple dup groups, which then broadcast to the rate limiter
registers.

This patch adds an API to configure addresses to the master dup group.
