[SW-228479]: security: gaudi3: Enhance security features in Makefile with additional compiler flags

This commit updates the BOOT_ROM_CFLAGS in the Makefile to
include several security-related compiler flags.

-D_FORTIFY_SOURCE=2: Enables compile-time and runtime checks
for buffer overflows in certain functions, enhancing security
against such vulnerabilities.

-fstack-protector-all: Adds stack canaries to all functions,
providing protection against stack buffer overflow attacks.

-Wl,-z,now: Enables full RELRO, which helps protect against
certain types of memory corruption attacks by making the
relocation sections read-only. This helps protect against
memory corruption attacks such as GOT overwrite attacks,
function pointer hijacking, and return-to-libc attacks.

-fPIE -pie: Generates position-independent code and links it as
a position-independent executable, which is useful for
Address Space Layout Randomization (ASLR).
