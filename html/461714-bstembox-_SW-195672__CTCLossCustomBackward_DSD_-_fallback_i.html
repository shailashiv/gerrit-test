Commit Message

[SW-195672] CTCLossCustomBackward DSD - fallback in case of wrong inputs shape: Reland

The size of the last dim of the log_alpha input tensor should be equal to the
size of the input tensor target[last_dim] * 2 + 1. If this condition is not met
during max shape inference pass, the fallback to the next policy should
be triggered.
