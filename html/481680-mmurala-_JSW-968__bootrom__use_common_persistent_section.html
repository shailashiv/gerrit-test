Commit Message

[JSW-968] bootrom: use common persistent section

BootROM has persistent DCCM section which is
split into 2 parts for different usage.
rom_persistent section and manifest section
can share common persistent dccm section.
There should not be any pre-init values for
persistent section, because it was cleared by
bootrom main and rom to dccm copy was not taken
care in main code. Hence, Need to assign them
after dccm clear in boot rom main, in case any
pre-init values required.
