Commit Message

[FSW-14755] fs1: wait for spi dma chunk copy

At present spi dma status done bit is used to
identify dma copy completed, it is a short pulse
and only useful if we start checking this bit
immediately. In case of just initialize copy and
check its status after some predefined operations
completed, this done was not useful and it may be
cleared before bootrom check for this. So we use
copied count here after.
