Commit Message

[SW-230471] g3: mgmt: add secure prot bit config

Add header file for secure protection bits to enhance register access
control. Previously, privilege settings were configured to restrict
access from all non-privileged entities, including both secure and
user-level initiators.

This patch introduces secure protection settings that specifically
restrict access from user-level entities while continuing to allow
access from both privileged and secure initiators. This enables more
flexible configuration where registers can be protected from user
access but remain accessible to secure and privileged entities.

This patch also renames existing privilege protection bits header
file.
