Commit Message

[SW-207417] gaudi3: lock interrupts while sending heartbeat

Whenever there is flood of interrupts, arcevent remains busy
executing ISRs or pre-empting from main thread to process
ISR and push interrupt to be processed in main thread. In such
scenarios, arcevent fails to send heartbeat to arcmgmt. This patch
locks interrupt in heartbeat send function.
