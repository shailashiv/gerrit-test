[PNP-174] api: update tdp input validation

The API input validation will limit TDP inputs above bit 11 (2048W).

Scale validation managed to reach 2100W peaks in their torture tests, so
we should ease this limit to allow better tests.

Change the limit to bit 12 (4096W).
