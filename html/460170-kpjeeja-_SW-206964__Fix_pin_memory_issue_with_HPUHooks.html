Commit Message

[SW-206964] Fix pin memory issue with HPUHooks

pin_memory can be called before creating hpu device. since
device is not initialized it fails with "expected
device_context.device_", So initialize the device before
calling getPinnedMemoryAllocator.

Example:
import torch
import habana_frameworks.torch.hpu
ifm = torch.tensor([[1,2,3, 4], [4,5,6, 8]], dtype=torch.float32)
ifm = ifm.pin_memory()
ifm.is_pinned()
