[SW-209955] fw-loader: fail if wrong fit provided

We want to fail the fw update if a wrong FIT
(G2 instead of G3 or G3 instead of G2) is provided.
We have to check in the fw-loader Agent and in the Preboot
(to cover bad FW loader Agent case).
In this current commit, we do the changes needed for the Agent part.
Changes in Preboot part will be handled in a separate commit.
Builds of G2 and G3 have been checked.
Run on G3 has been checked.
