Commit Message

[SW-230471] specs: add enum to define protection bit types

This patch adds an enum to represent protection levels for register
access. This helps distinguish between privilege-based protection
(blocks secure and user initiators) and secure-based protection
(blocks only user initiators). This will allow more granular access
control where needed.
