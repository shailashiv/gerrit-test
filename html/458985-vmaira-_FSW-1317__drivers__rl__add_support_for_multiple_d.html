Commit Message

[FSW-1317] drivers: rl: add support for multiple dup group usage

In FS1, we need to configure 160 instances of CU_RRTR rate limiters on
the compute die. Since FS1 dup groups support broadcasting to only 32
addresses, multiple dup groups are required.

This patch updates the rate limiter driver to use multiple dup groups
for rate limiter programming when the number of configurations needed
for an engine exceeds the number of addresses supported by an
individual dup group.
