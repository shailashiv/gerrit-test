Commit Message

[JSW-969] jgs: manifest improvements

This patch has changes related to boot flow to
simplify the usage of manifest index and type.
Added simplified prefetch status structure to
maintain prefetch status as done, failed, valid,
and manifest index based on fw update/flip.
Used very simple approach to maintain manifest
type with structure array, to avoid frequent
manifest index switching based on type.
