Commit Message

[SW-211875] drivers: pll: optimize dccm consumption

Currently, for gaudi3 arcpid dccm is short of few tens of bytes before
overflowing. This patch reduces the number of bytes used to store
'div sel'. The div sel value ranges from 0 to 3, representing ref clk,
divided ref clk, pll clock and divided pll clock. Since, 1 byte is
sufficient to hold the div sel value, this patch changes the type of
div sel from uint32_t to uint8_t.
