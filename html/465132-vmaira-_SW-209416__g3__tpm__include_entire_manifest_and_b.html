[SW-209416] g3: tpm: include entire manifest and boot fit for pcr gen

Earlier, manifest header(includes SVN, key index), public key,
signature and CRC were excluded during manifest hash calculation.
Similarly during boot fit hash calculation security footer was
excluded.

The exclusion was a temporary fix to avoid regenerating the PCR
after signing with a new key, as signing alters key index, key,
and signature fields.

This patch updates the process to include the entire manifest
(excluding the crc bytes)and boot fit for TPM PCR binary generation.
The CRC bytes from the manifest are excluded during TPM PCR binary
generation to align with ppboot, which also excludes CRC bytes in
manifest during manifest hash generation. This ensures consistency
across both processes.
