Commit Message

[SW-232549] g3: use busy-wait polling to avoid CPU yield in k_poll

This patch prevents k_poll from yielding the CPU, which could
allow another thread to disable interrupts and prevent the ISR from
delivering the awaited data. Ensures the polling thread remains active
and responsive to ISR updates.
