Commit Message

[SW-227647] ipm: prevent compiler optimisation

Ensures proper volatile qualification of the msg pointer.
Without this qualifier, compiler optimizations
can cause register caching and memory access reordering,
resulting in intermittent failures where interrupt processing might see
partially updated message fields.
