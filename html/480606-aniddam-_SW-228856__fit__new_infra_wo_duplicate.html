[SW-228856] fit: new infra wo duplicate

We encountered several code duplications related to
fit_foreach_property.
So, we create a new fit services infrastructure to solve
this issue in a clean way.
The main lego pieces are the newly created:
fit_services.c/h located (in emb_common_mod).
This infra is ready and so far it supports the use of
fit_foreach_property
But potentially, it can support ANY of the
fit related functions that we find today in fit_utils.c
or fit.c
Therefore, from now, please, anyone doing an infrastructure
change related to the fit files should carefully double-check:
Any unfied code can be and should be located in
fit_services.c/h
For this, please, follow the example of how it has been
done with fit_foreach_property.

+int fit_foreach_property(const void *fit, const char *node_path,
+			fit_property_match_cb match_cb, void *data)
+{
+	int ret, count = 0;
+	int noffset, property;
+	const struct fdt_property *prop;
+
+	noffset = fdt_path_offset(fit, node_path);
+	if (noffset < 0) {
+		EMB_LOG_RAW_ERR("Cannot find entry ");
+		EMB_LOG_RAW(node_path);
+		EMB_LOG_RAW("\n\r");
+		return -1;
+	}
+
+	fdt_for_each_property_offset(property, fit, noffset) {
+		prop = fdt_get_property_by_offset(fit, property, NULL);
+		if (!prop)
+			continue;
+
+		ret = match_cb(fit, prop, data);
+		if (!ret)
+			count++;
+	}
+
+	return count;
