[SW-209416] g3: tpm: include full manifest in hash calc for tpm pcrs

Earlier, manifest hash was calculated on manifest image after excluding
manifest header(includes SVN, key index), public key, signature and
CRC from it. This hash was extended to TPM PCR.

The exclusion was a temporary fix to avoid regenerating the PCR after
signing with a new key, as signing alters key index, key, and signature
fields.

Ideally, the PCR should be generated based on the hash of the full
manifest. This patch updates the process to include the full manifest
for manifest hash calculation in ppboot.
