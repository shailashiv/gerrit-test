Commit Message

[SW-201116] g3: sec: soft reset pre and post sec config

This patch adds pre soft reset and post post soft reset
securtiy configuration.
During soft reset only nic cfg, nic dbg, vuart registers
and D0_PARC_ARC1_CFG ➔ EQ_RD_OFFS are required to be open.

In soft reset all engines are halted so blocking
all CFG range except PCIE_AUX(vuart), NIC CFG &
D0_PARC_ARC1_CFG in PCIE_MSTR_IF ISEC and blocking all CFG
range except PCIE_CORE(telemetry), PCIE_AUX(vuart) & NIC CFG
in ELBI_MSTR_IF ISEC blocks all transactions.
