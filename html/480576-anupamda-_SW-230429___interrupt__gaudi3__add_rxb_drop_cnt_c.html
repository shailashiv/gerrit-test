Commit Message

[SW-230429]: interrupt: gaudi3: add rxb_drop_cnt coalescing

- Problem: Frequent packet drops in NIC RXB_CORE can
  generate a large number of software error events,
  potentially overwhelming the system.
- Introduced per-instance and per-die coalescing for
  NIC RXB packet drop events (PKT_DROP_NO_CRDT_S) in
  gaudi3_process_nic_sw_error() to reduce event flooding
  and improve system stability.
- If packet drops are detected, increment the counter
  and only send an event if the timeout
  (PACKET_DROP_COUNT_TIMEOUT_MS) has been exceeded,
  then reset the counter and timestamp.
- If no packet drop is detected, send the event
  immediately as before.
- During coalescing, `notify_lkd` is set to false to
  ensure the interrupt driver unmasks the interrupt
  directly, since the event is not sent to LKD and
  LKD would otherwise not issue an unmask.
