[SW-200551] dts: arc: gaudi3: pid: disable pwrbrk for c2m and mesh

While running F2 extreme workloads, watchdog issue is observed
when system is put in power break mode. Ideally the workloads should
run okay (even though slower) when system is in power break mode.

This patch keep C2M and MESH which are fabric PLL in POR frequency
while in powerbreak with which watchdog issue is not observed and
F2 extreme test runs successfully.
