Commit Message

[SIV-5885] drivers: hbm: gaudi3: move rl fix after extest

HBM reset is added after phy io dc as part of the
wa SIV-5885. This is causing issue in aligning the
hbm remap code on efuse burnt cards. Hence moving
the hbm reset before the remap alignment and soon
after extest.
