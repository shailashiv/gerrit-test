Commit Message

[SW-209416] g3: tpm: include security footer in fit hash calc

Previously, the manifest hash was calculated by excluding the manifest
header (including SVN and key index), public key, signature, and CRC
from the manifest image. This hash was extended to the TPM PCR. The
exclusion was a temporary workaround to avoid PCR regeneration when
signing with a new key, as signing modifies the key index, key, and
signature fields.

For manifest hash calculation, ppboot reuses the manifest image already
present in ICCM memory instead of reading from flash. Manifest image is
copied from flash to ICCM memory by the bootrom. The bootrom uses a DMA
engine for this transfer, which skips copying the CRC region and instead
uses the CRC bytes only to verify the transfer's success. As a result,
the manifest hash calculation excludes the 4-byte CRC since it is not
present in the ICCM copy.

Ideally, the PCR should be derived from the hash of the complete
manifest. This patch updates the process in ppboot to calculate the
manifest hash using the full manifest image, excluding only the CRC
bytes.
