Commit Message

[SW-229897] gaudi3: change spi wareout trigger data

To enable SPI wareout we need to do a dummy write
to flash. For this we were writing 0xFFFFFFFF to the unused
28th sector. This was causing data corruption issue due to
4 bytes data being overwritten in case the 28th sector held some
valid data.
To avoid this, we will read back 4 bytes of data from the sector
being used to trigger Wareout timer and program back the same.
